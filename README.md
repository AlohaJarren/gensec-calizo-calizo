# Generative Security AI - CS 575

This repository contains my generative AI security coursework at Portland State University. I worked on RAG tools for searching text, agents that use external tools, an MCP-based SSH vulnerability advisor, and Python code triage. I also used Promptfoo to test a deliberately vulnerable chatbot for prompt injection and information leakage.

For the final project, I built a defensive social engineering autoresponder. It classifies suspicious messages by scam type, risk, and conversation stage, then replies through a fictional persona with rules designed to avoid sharing sensitive information. I added conversation history, transcript logs, and exports so I could review how it responded to different scenarios.
